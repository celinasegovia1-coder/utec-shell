# Init files, variables and expansions

Este directorio contiene scripts de Bash sobre la inicialización de archivos, variables y expansiones de Shell.

## Scripts

* `0-alias`: Script que crea un alias llamado `ls` con el valor `rm -f *`.
* `1-hello_you`: Script que imprime "hello" seguido del nombre del usuario actual.
* `2-path`: Script que añade `/action` al final de la variable PATH.
